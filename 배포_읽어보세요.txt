NAI Studio — 배포본 사용법
==========================

받은 것: NAI-Studio.exe  (파일 하나. 설치 필요 없음)


처음 쓰기
---------
1. exe 를 원하는 폴더에 두고 더블클릭합니다.
   → 검은 창이 뜨고 브라우저가 자동으로 열립니다.
   → exe 옆에 data\ 폴더가 생깁니다. 설정·이미지가 전부 여기 저장됩니다.
      (exe 를 옮길 땐 data\ 폴더도 같이 옮기세요)

2. 오른쪽 위 ⚙설정 → NovelAI API 토큰 을 넣습니다.
   novelai.net → Settings → Account → Get Persistent API Token
   ※ NovelAI 유료 구독이 있어야 합니다.

3. 끝. 검은 창을 닫으면 앱이 꺼집니다. 최소화해 두세요.


선택 설정
---------
· Gemini API 키 (⚙설정)
  ✨AI 버튼 - 한국어로 장면을 쓰면 단부루 태그로 바꿔줍니다.
  https://aistudio.google.com/apikey 에서 무료 발급.

· 유튜브 480p 이상 재생
  Node.js 가 설치돼 있으면 화질이 올라갑니다 (https://nodejs.org).
  없어도 재생은 됩니다.


주요 기능
---------
· 메인      생성 · i2i · 인페인트 · 바이브 · 캐릭터 프롬프트 · 실시간 미리보기
· 씬 모드    장면별 프롬프트로 자동 짤뽑 (기본 프롬프트를 이어받습니다)
· 스마트 툴   배경제거 · 라인아트 · 스케치 · 채색 · 표정변경 · 업스케일 · 모자이크/검열
· 라이브러리  생성한 이미지 모아보기 · 선택 저장/삭제
· 🔎태그     한글로 검색 (22만 태그, 한글 문장 검색 지원)
· 🎨작가     작가 태그를 실제 그림 샘플과 함께 찾아보기
· 🎵        유튜브 검색·재생 (앱 안에서)


자주 묻는 것
------------
Q. 백신이 경고합니다
A. 서명되지 않은 PyInstaller 실행 파일이라 그렇습니다. 걱정되시면
   소스를 직접 받아 build.bat 으로 빌드해 쓰세요.

Q. 작가 그림 샘플이 안 뜹니다
A. 국내 회선에서 danbooru 가 차단돼 있습니다. safebooru 로 자동 전환되지만
   그것도 막히면 샘플만 안 나오고 나머지는 정상 동작합니다.

Q. 설정을 다른 PC 로 옮기려면
A. 📦 버튼 → 전체 백업 으로 ZIP 을 만들어 옮기고 복원하면 됩니다.
   (또는 data\ 폴더째 복사)

Q. 토큰이 어디 저장되나요
A. data\config.json 입니다. 이 파일은 남에게 주면 안 됩니다.
