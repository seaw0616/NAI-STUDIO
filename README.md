# NAI Studio

NovelAI 이미지 생성을 위한 **로컬 데스크톱 스튜디오**. 실행 파일 하나로 돌아갑니다.

NAI 웹과 **같은 결과물**이 나오도록 요청 규격을 실제 캡처와 대조해 맞췄고, 짤뽑·태그 검색·씬 모드·이미지 후처리·유튜브까지 한 화면에 넣었습니다.

> ⚠️ 비공식 도구입니다. NovelAI · Danbooru · YouTube · Google 과 제휴 관계가 없습니다.
> 사용하려면 **NovelAI 유료 구독과 API 토큰**이 필요합니다.

---

## 설치

1. [Releases](../../releases/latest) 에서 **`NAI-Studio.exe`** 를 받습니다.
2. 원하는 폴더에 두고 더블클릭합니다. (설치 과정 없음)
3. 브라우저가 자동으로 열립니다. **⚙ 설정 → NovelAI API 토큰** 을 넣으면 끝입니다.
   - 토큰: novelai.net → Settings → Account → **Get Persistent API Token**

exe 옆에 `data\` 폴더가 생기고 설정·이미지가 전부 여기 저장됩니다. **exe 를 옮길 땐 `data\` 도 같이 옮기세요.**

> 백신이 경고할 수 있습니다. 서명되지 않은 PyInstaller 실행 파일이라 흔한 일입니다.
> 걱정되시면 아래 "직접 빌드"로 소스에서 만들어 쓰세요.

### 선택 설정

| 항목 | 용도 |
|---|---|
| **Gemini API 키** (⚙설정) | ✨AI 버튼 — 한국어 장면 설명을 단부루 태그로 변환. [무료 발급](https://aistudio.google.com/apikey) |
| **Node.js** ([nodejs.org](https://nodejs.org)) | 유튜브 480p 이상 재생. 없어도 재생은 됩니다 |

## 기능

### 생성
- V4.5 Full/Curated · V4 Full/Curated · Anime V3 · **Furry V3**
- **실시간 미리보기** — 생성 과정을 스텝별로 보면서 도중 취소 가능
- i2i · 인페인트(마스크 브러시) · 바이브 트랜스퍼 · **Precise Reference**(V4.5)
- 캐릭터 프롬프트(V4+) · 좌표 지정 · AI 자동 배치
- Variety+ · Decrisper · SMEA/DYN(V3) · 샘플러·스케줄 전체 지원
- **Anlas 비용을 미리 표시** — Opus 무료 조건까지 계산

NAI 웹에서 캡처한 실제 요청과 대조해 payload 를 맞췄습니다. 같은 시드·같은 설정이면 웹과 같은 그림이 나옵니다.

### 프롬프트
- **청크** — 자주 쓰는 프롬프트를 이름으로 저장, 이름만 치면 펼쳐짐
- **조각** — 여러 줄 청크를 `<이름>` 으로 부르면 매번 한 줄씩 랜덤. `<*이름>` 은 순서대로
- `<a|b|c>` 인라인 랜덤 · 스타일 프리셋(앞/뒤 고정 프롬프트) · 캐릭터 라이브러리
- 프롬프트 칸을 원하는 구성으로 편집 (기본 5칸: 중요태그 / 외모 / 행동 / 배경 / 구도)
- **토큰 카운터** — T5 기준 `36/512`. 넘치면 경고
- Ctrl+↑/↓ 로 가중치 조절 (V4 `1.05::tag::` · V3 `{tag}`/`[tag]`)

### 태그
- **225,324개** 태그 사전 (작가 93,362 · 캐릭터 71,876)
- **한글로 검색** — `검은머리`, `얼굴이 작다` 같은 문장도 됩니다
- 검색 응답 **0~7ms** (단어시작 인덱스)
- **📚 그룹 탐색** — 263개 분류를 훑어보며 태그 발견
- **🎨 작가 브라우저** — 작가 태그를 실제 그림 샘플과 함께 확인, 비슷한 작가 추천

### 씬 모드
장면별 프롬프트를 만들어 두고 순서대로 자동 생성. 기본 프롬프트를 그대로 이어받고 씬에는 **덧붙일 것만** 쓰면 됩니다.

### 스마트 툴
배경 제거 · 라인아트 추출 · 스케치 변환 · 이미지 정리(말풍선 유지 옵션) · 채색 · 표정 변경 · 업스케일(2×/4×) · i2i · 인페인트 · **모자이크/검열** · 메타데이터 제거

### 그 외
- **NAI 상태 종합 판정** — 공식 상태 + 내 생성 속도(과거 대비 배율) + 실패율 + 그림 품질을 종합. Gemini 로 손가락·해부학·프롬프트 준수도 채점도 가능
- **유튜브** — 앱 안에서 검색·재생. 알고리즘 이어듣기, 최대 1080p
- NAI PNG 를 끌어다 놓으면 그 설정 그대로 재현
- EXIF·숨은 메타데이터(stealth pnginfo) 제거
- 전체 백업/복원 (설정 + 이미지 ZIP)
- 테마 10종 (다크·라이트·멘헤라·사쿠라·민트 등)

## 직접 빌드

```bat
git clone https://github.com/seaw0616/NAI-STUDIO.git
cd NAI-STUDIO
build.bat
```

`build.bat` 이 빌드용 가상환경을 만들고 `dist\NAI-Studio.exe` 를 생성합니다. Python 3.10+ 이 필요합니다.

소스로 바로 실행하려면 `start.bat` 을 쓰면 됩니다 (빌드 불필요).

## 자주 묻는 것

**Q. 작가 그림 샘플이 안 뜹니다**
국내 회선에서 danbooru 가 차단돼 있습니다. safebooru 로 자동 전환되지만 그것도 막히면 샘플만 안 나오고 나머지는 정상입니다.

**Q. 설정을 다른 PC 로 옮기려면?**
📦 버튼 → 전체 백업 으로 ZIP 을 만들어 옮기고 복원하면 됩니다. (또는 `data\` 폴더째 복사)

**Q. 토큰은 어디 저장되나요?**
`data\config.json` 입니다. **이 파일은 절대 남에게 주지 마세요.** 저장소에도 올라가지 않도록 `.gitignore` 에 넣어두었습니다.

**Q. 업데이트는?**
새 버전이 나오면 앱 상단에 **⬆ 업데이트** 버튼이 뜹니다. 눌러서 받고 "적용하고 재시작" 하면 끝입니다.
