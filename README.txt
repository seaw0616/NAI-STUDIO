  NAI Studio v4 — 로컬 NovelAI 이미지 생성 스튜디오

■ 실행
  ★ 바탕화면 바로가기 "NAI Studio (Chrome)" 더블클릭 (= start-chrome.bat). 작업표시줄에 고정하려면 실행 중 아이콘 우클릭 → 고정.
  1. start.bat 더블클릭 → 검은 창 + 기본 브라우저 자동 열림 (http://127.0.0.1:8765/)
     ★ start-chrome.bat / start-edge.bat : Chrome/Edge를 "앱 모드"(주소창 없는 창)로 열어줌.
       Chrome·Edge에서는 유튜브 내장 플레이어가 브라우저의 로그인 계정으로 재생되어(Premium이면 광고 없음)
       팝업 없이 앱 안에서 음악을 들을 수 있고, 폴더 자동 저장(폴더 선택)도 됩니다. Firefox는 둘 다 안 됨.
  2. 좌상단 ● 초록 "서버 연결됨" 확인 (빨간 배너면 start.bat 꺼짐)
  3. [⚙] → 토큰 붙여넣기 → [토큰 저장 + 연결 테스트] → "✔ 연결 성공 · Anlas ####"
     ※ 토큰은 로컬 서버 파일(data/config.json)에 저장되므로 브라우저를 바꾸거나 쿠키를 지워도 유지됩니다.
     ※ "토큰 없음"이 계속 뜨면 ⚙ 안의 "진단" 줄을 보고 알려주세요 (서버 연결/토큰 위치/마지막 API 오류가 표시됨).
  4. 프롬프트 → [✦ 생성] (Ctrl+Enter)

■ NAI 웹과 결과가 다를 때 (재현 체크)
  📥 NAI PNG → "🔬 재현 검증": 같은 설정·시드로 1장 생성해 두 이미지를 나란히 놓고 픽셀 일치율을 보여줍니다.
  일치하면 앱은 NAI 웹과 동일하게 동작하는 것 (평소 차이 = 설정/시드), 다르면 "두 메타데이터 비교"에서 빨간 줄을 알려주세요.
  NAI 웹에서 뽑은 PNG를 ⚙ 설정 아래 "NAI PNG 드롭"에 넣으면 프롬프트·시드·스텝·가이던스·리스케일·샘플러·
  노이즈 스케줄·UC 프리셋·Variety·Decrisper·SMEA·캐릭터가 전부 그대로 복원됩니다. 그 상태로 [생성]하면
  같은 이미지가 나와야 정상입니다. (같은 프롬프트라도 시드가 다르면 당연히 다른 그림이 나옵니다.)
  NAI 웹 기본값: 스텝 28 · 가이던스 5 · 리스케일 0 · Euler Ancestral · karras · UC Heavy · 퀄리티 태그 ON
  NAI 웹 숨은 규칙(앱도 동일, 옵션 "네거티브에 nsfw 자동 추가"): 프롬프트에 nsfw가 없으면 네거티브 맨 앞에 "nsfw, " 추가
  (Curated 모델·UC 프리셋 "없음"은 제외). 검증 결과 앱 생성 = NAI 웹 픽셀 100% 일치.

■ 화면 (상단 탭)
  [메인]      가운데 = 큰 이미지 화면 + [✦ 생성] (□연속 체크 시 = 짤뽑 시작/정지)
              왼쪽  = 모델·크기 → 프롬프트 칸들 → 이미지 입력(i2i·바이브·레퍼런스) → 샘플링 → 옵션 → 인핸스
              오른쪽 = 시드 → 짤뽑(횟수·간격·방식) → 자동 저장 → 히스토리
              프롬프트 칸: NAI 권장 순서 ① 캐릭터·외모 ② 행동·포즈·표정 ③ 배경·상황 ④ 구도·스타일 — 위→아래로 이어져 하나의 프롬프트.
                [⚙ 칸]에서 칸 추가/이름/설명/순서 변경, "한 칸으로 쓰기" 전환.
              짤뽑 방식: 🎲 매번 랜덤 조합(<a|b>·청크 새로 뽑음) / 📌 지금 조합 고정(시드만 변경)
              상단 "NAI ●" = NovelAI 서버 상태(응답 속도·공지·내 생성 평균 시간, 클릭하면 상세)
  [씬 모드]   씬별 프롬프트·방향·장수·캐릭터 → ▶ 자동 짤뽑, 전체 씬 순서대로 생성, 씬별 즐겨찾기/삭제/저장,
              감정 12종 세트, 자동 저장 시 씬 이름 하위 폴더
  [라이브러리] 전체 이미지 크게 보기, 씬/즐겨찾기 필터, 다중 선택 저장/삭제
  ☀/🌙        다크↔라이트 빠른 전환. ⚙에서 테마 10종:
              🌙 Violet Night · Deep Ocean · Forest · Gold Noir · 멘헤라 나이트
              ☀ Clean Light · NAI Pink · 멘헤라 · 사쿠라 · 민트

■ 프롬프트 도구
  태그      한글/영어 자동완성 (흰머리→white hair), 🔎 태그 검색(Ctrl+K) 11만 태그 한글 설명
  🧩 청크    자주 쓰는 조각. 칩 클릭 = 프롬프트에 청크 이름이 색칠된 태그로 들어감 → 생성 시 내용으로 치환
             칩/분류 우클릭 = 편집·삭제·분류 이동·분류 이름 변경/삭제. 🧩 관리창에서 분류별로 보기·새 분류
             (Alt+클릭 = 내용 그대로). 프롬프트에 청크 이름을 직접 타이핑해도 자동으로 칩이 되고 치환됩니다.
             자동완성에서 '@' 또는 이름 2글자를 치면 청크 목록이 뜸. <a|b|c> 랜덤 가능
  🎨 스타일  고정 프롬프트(작화·품질·체형·기본 네거) — 앞/뒤/네거로 저장해 메인·씬 프롬프트를 감쌈
  👤 캐릭터  캐릭터 라이브러리 — 저장해 두고 메인/씬 캐릭터 카드에서 "라이브러리…"로 불러오기, 청크로도 저장

     내장 플레이어에 계정을 쓰려면 Firefox: 주소창 🛡 방패 → "이 사이트 보호 끄기" / Chrome: 서드파티 쿠키 허용
